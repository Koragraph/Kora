Kora's first beta: Kora Code.

What's in it:

- **Claude Code, with a map of your code.** Kora keeps a local code graph of your project and hands Claude the right declarations with each message, so it reads fewer files and uses fewer tokens.
- **Threads in your repos:** pick any Claude model and effort, and set permissions per thread. Approvals and questions show up in the sidebar.
- **Swarm:** hand slices of work to workers on free models. Each worker runs in its own worktree, you approve every worker before it starts, and you merge their work when it's done.
- **Safer:**
  - Kora stops an agent and asks before it reads or changes your SSH keys, cloud credentials or Kora's own token, through file tools, shell commands or links that point at them. It's a guard, not a sandbox: a script that builds such a path while it runs can get past it.
  - Kora never writes into a folder you haven't trusted.
  - The app runs on Electron 44.7, with Electron's debug and run-as-node switches turned off.
- **Indexing:** Kora never indexes a project on its own. Indexing starts only when you click to index, and never for your home folder or a system or temp folder.
- **Local:** no Kora account and no analytics. Your code and chats stay on your Mac.
- **Coming soon:** Kora, a team of assistants with their own memory, routines and browser.

Requires an Apple Silicon Mac, macOS 13.5 or later, and a Claude plan (Kora signs you in from the app). Found a problem? Use Help → Report a Bug… in the app.
