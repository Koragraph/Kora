The first Kora release: two surfaces, Kora and Code.

What's in it:

- Kora (assistants): pixel-sprite team with their own folders, memory and routines. Kora the Chief can hand work to other assistants.
- Safer: assistants ask before shell commands beyond plain file work, and Kora stops an agent and asks before it reads or changes your SSH keys, cloud credentials or Kora's own token, through file tools or shell commands that point at them. It's a guard, not a sandbox: a script that builds such a path while it runs can get past it.
- Memory is more reliable: facts about other people no longer overwrite yours, and a restart no longer resets your shared notes. Forget removes the chat lines and summaries that said the fact right away, and the fact itself once its Undo window has passed.
- Costs less in the background: memory upkeep no longer uses your Claude plan unless you allow it, routines have run limits and pause themselves after repeated failures, and usage counters show real totals.
- Stop now stops everything: swarm workers and Kora's jobs end, and finished workers are cleaned up.
- Clearer first run: sign-in is visible on the first screen, and the README and settings explain what runs in the background.
- Kora never indexes your home folder or a system or temp folder. Opening a project never indexes it on its own: indexing starts only when you click to index.

Requires an Apple Silicon Mac, macOS 13.5 or later, and a Claude plan (Kora signs you in from the app). Found a problem?
