- **Four agents:** Kora works with Claude Code, Codex, OpenCode and Antigravity. The first screen is ready as soon as any one of them is installed and signed in; Claude keeps its one-click login, and the others say how to sign in.
- **"Kora saved you" for every agent:** the savings meter now counts Codex, OpenCode and Antigravity threads too, each at its own model's API list price (Claude at Anthropic's, GPT at OpenAI's, Gemini at Google's). The price list updates itself once a day, so a new model is priced without a Kora update; a model with no public price yet is named and left out, never guessed. Kora also now counts the Claude Code tools it removes from every Claude thread, which it used to leave out.
- **Plan mode:** a Plan button in the composer. Each agent plans in its own way (Claude's plan mode, Codex read-only, OpenCode's plan agent) with the code graph behind it, and nothing is changed until you choose Build it.
- **Stretch:** the Swarm button is now **Stretch**, one button for making your usage last. Your agent does small work itself and hands the rest to the cheapest option that can do it: free models first, then cheap Claude Haiku or GPT Luna workers if no free one is available. Any of Claude, Codex or OpenCode can lead. Pressing it is the approval, and it only ever allows those cheap models; you can watch every worker. If a free worker goes quiet, Kora parks that model for 10 minutes and moves the task to another one, and your agent is told to hand a slow free worker to the cheap tier. The Swarm page in Settings is now headed Stretch.
- **Auto model is off by default:** it saved close to nothing in real use (a chat that starts light usually turns into real work and has to move up). New chats start on your default model. You can still turn it on in Settings › Token savings.
- **Code graph for OpenCode:** OpenCode threads now get the same code lookups as Claude and Codex threads.
- **OpenCode chats work in your project:** an OpenCode chat used to run in the folder the Kora daemon was started from instead of your project. Fixed for chats, Swarm reviews and helper calls.
- **Safer workers:** an agent can no longer stop other agents' processes with a pattern kill (`pkill`, `killall`); it has to stop the exact process it started.
- **Workers:** a worker woken up for more work now receives the message (it used to sit with the text unsent), and a worker that can't resume its old session says so and is given its task again. OpenCode workers no longer get stuck on OpenCode's "Update Available" dialog, a worker whose model stops answering is moved to another model after 4 minutes, and Kora's own nudges no longer count as the worker making progress.
- **Effort:** a new sectioned effort slider for every model that has effort levels: Claude, Codex and OpenCode. Drag it, throw it or use the arrow keys.
- **Model picker:** a more compact layout. The OpenCode tab lists every model your own OpenCode login can run, not just the free ones, and its effort setting is sent to the model.
- **Smaller fixes:** the Workers panel's old "Blob mode" button is now "Close"; switching Stretch on or off reads "Stretch on" / "Stretch off"; a GPT model name stays readable in the sidebar; Codex tool calls show their real names; the first-run note about full access names your agents, not only Claude.
- **Settings:** Token savings has its own page, unused fields are gone from the agent cards, and Diagnostics counts a problem only when none of your agents works.
- **Startup:** the slow-start notice waits 30 s again. A port that is already taken is still reported after 5 s.
- **Health:** no PATH warning when your shell startup file already adds `~/.local/bin`.
- **Fixes:** a page error on Settings › Token savings, an error when clicking elsewhere while a file was still opening, and assorted stability fixes. Security updates for bundled libraries.
